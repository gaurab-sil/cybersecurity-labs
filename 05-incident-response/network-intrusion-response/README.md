# Network Intrusion Incident Response

## Overview

This project documents a structured incident response exercise
based on a suspected network intrusion following interaction
with a suspicious email link.

The exercise focuses on detection, investigation, containment,
eradication and recovery.

## Incident Severity

High

## Initial Scenario

A user interacted with a suspicious link received through
corporate email.

The response process considers the possibility of:

- Unauthorised access
- Credential compromise
- Malware infection
- Data exposure

## 1. Detection and Analysis

The investigation begins by reviewing available security
telemetry and identifying the potential attack method,
entry point and scope.

Investigation sources include:

- Email security logs
- Firewall logs
- Endpoint detection alerts
- SIEM monitoring
- Authentication logs
- System logs
- Browser history
- Email headers
- Downloaded content

## 2. Evidence Preservation

Relevant evidence should be preserved during investigation
to support forensic analysis and maintain an accurate record
of the incident.

## 3. Containment

Potential containment actions include:

- Disconnecting the affected device from the network
- Resetting passwords
- Disabling compromised accounts where necessary
- Blocking malicious links
- Blocking malicious senders

## 4. Eradication

Eradication activities may include:

- Removing malware
- Patching vulnerabilities
- Updating security tools
- Rebuilding or reimaging affected systems when required

## 5. Recovery

Systems should only be returned to normal operation after
security validation.

Recovery activities include:

- Restoring trusted backups where required
- Verifying system security
- Increasing monitoring
- Completing final incident documentation

## 6. Roles and Responsibilities

### Cybersecurity Analyst

- Investigate the incident
- Identify the root cause
- Analyse potential impact
- Collect forensic evidence
- Implement response actions

### IT Manager

- Coordinate the response
- Ensure procedures are followed
- Coordinate technical teams
- Approve remediation actions

### IT Support

- Assist with device isolation
- Support security scanning
- Assist with malware remediation
- Rebuild or reimage systems where required
