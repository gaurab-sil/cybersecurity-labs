# Incident Response Labs

This section contains practical incident response exercises
completed as part of an authorised cybersecurity training
environment.

## Project

### Network Intrusion Incident Response

A structured incident response exercise involving a suspected
network intrusion following interaction with a suspicious
email link.

The exercise focused on investigating the incident, assessing
potential impact, collecting evidence and developing
containment, eradication and recovery actions.
