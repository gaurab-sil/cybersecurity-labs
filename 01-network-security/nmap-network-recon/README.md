# Nmap Network Reconnaissance

## Overview

A hands-on network reconnaissance exercise using Nmap
to identify active hosts, open ports and running services
within a controlled lab environment.

## Objectives

- Discover active hosts
- Identify open ports
- Enumerate network services
- Analyse the discovered attack surface

## Tool Used

- Nmap
- Kali Linux

## Methodology

1. Identify the local network range
2. Perform host discovery
3. Scan for open ports
4. Identify services running on discovered ports
5. Document the results
6. Assess the exposed attack surface

## Evidence

Screenshots and scan results demonstrate the reconnaissance
and enumeration process.

## Environment

Controlled educational cybersecurity lab.

## Disclaimer

This activity was performed in an authorised educational
environment for cybersecurity learning purposes.
