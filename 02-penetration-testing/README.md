# Penetration Testing Labs

This section contains hands-on penetration testing exercises
completed in controlled educational cybersecurity laboratories.

## Skills Demonstrated

- Network discovery
- Service enumeration
- Port scanning
- Vulnerability identification
- Vulnerability research
- Metasploit framework
- Exploitation in an authorised lab environment
- Post-exploitation analysis
- Security remediation

## Projects

### Basic Pentesting 1

A controlled penetration-testing exercise involving:

- Network discovery
- Nmap service enumeration
- Identification of vulnerable services
- Vulnerability research
- Metasploit exploitation
- Controlled shell access
- Security recommendations

## Tools

- Kali Linux
- Netdiscover
- Nmap
- virtualbox
- Metasploit Framework

## Authorisation

All testing was performed against intentionally vulnerable
systems in an authorised educational laboratory environment.

## Disclaimer

The original laboratory evidence has been sanitised before
publication. No real-world systems or unauthorised targets
were tested.
